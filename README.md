# 🌐 Rohit Sharma — 3D Animated Portfolio Website

Welcome to my personal 3D portfolio website — an interactive experience where every project comes alive with unique animations and immersive design. This site showcases my skills, projects, and creative journey in web development, AI, and design.

## 🚀 Features

- ✨ Advanced 3D animations with distinct transitions for each page
- 🧠 AI-enhanced interactive sections
- 📂 Dynamic project viewer with motion effects
- 🎨 Custom design with personalized themes
- 📱 Fully responsive and cross-browser compatible
- 🔐 Backend integration with secure forms and dynamic content

## 🛠️ Tech Stack

### Frontend
- `Three.js` / `GSAP` / `Spline` for 3D animations
- `React.js` or `Vanilla JS` (depending on your build)
- `TailwindCSS` / `Sass` for styling
- `Framer Motion` for smooth transitions

### Backend
- `Node.js + Express` or `Flask` (Python)
- `MongoDB` / `Firebase` / `PostgreSQL` for data handling
- `REST APIs` for dynamic sections like contact and blogs

### DevOps & Hosting
- `Vercel` / `Netlify` / `Render` (for frontend)
- `Railway` / `Heroku` / `AWS` (for backend)
- GitHub Actions (CI/CD)
